Creating a Systemd Service
You don't want your app to die when you close your SSH terminal. A systemd service keeps it running in the background automatically.

sudo nano /etc/systemd/system/myflaskapp.service

[Unit]
Description=Gunicorn instance to serve my flask app
After=network.target

[Service]
User=ubuntu
Group=www-data
WorkingDirectory=/home/ubuntu/travel-dashboard
Environment="PATH=/home/ubuntu/travel-dashboard/venv/bin"
ExecStart=/home/ubuntu/travel-dashboard/venv/bin/gunicorn --bind 0.0.0.0:8000 b>

[Install]
WantedBy=multi-user.target

10.

Configuring Nginx as a Reverse Proxy
Nginx handles incoming web traffic on port 80 (HTTP) and passes it to Gunicorn on port 8000. This is faster and more secure.    

sudo nano /etc/nginx/sites-available/myflaskapp

server {
    listen 80;
    server_name 3.133.107.69;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}

from geopy.geocoders import Nominatim

# Initialize the geolocator API with a custom user agent
# It is important to specify a user_agent unique to your application
geolocator = Nominatim(user_agent="your_app_name")

# Specify the city or location name
city_name = "New York City"

# Use the geocode method to get the location data

if location:
    print(f"City: {city_name}")
    print(f"Latitude: {location.latitude}")
    print(f"Longitude: {location.longitude}")
else:
    print(f"Could not find coordinates for {city_name}")
